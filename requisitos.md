# Documento de requisitos

## Requisitos funcionais

Permitir o cadastro de atividades.
Permitir o registro de datas de provas.
Permitir o registro de trabalhos escolares.
Permitir a consulta do calendário.
Permitir a visualização de eventos da escola.

## Requisitos não funcionais

O sistema deve ser fácil de utilizar.
O sistema deve funcionar em computadores.
O sistema deve funcionar em celulares.
O sistema deve ter uma interface simples.
