# 📋 Documento de Requisitos - Agenda CTBJ

## 1. Introdução

Este documento descreve os **requisitos funcionais** e **não funcionais** do sistema Agenda CTBJ, uma plataforma de organização escolar que auxilia alunos e professores no acompanhamento de provas, trabalhos, atividades e eventos.

---

## 2. Requisitos Funcionais

| Código | Descrição |
|--------|-----------|
| RF01 | O sistema deve permitir o cadastro de atividades escolares |
| RF02 | O sistema deve permitir o cadastro de provas informando disciplina e data |
| RF03 | O sistema deve permitir o cadastro de trabalhos e suas respectivas datas de entrega |
| RF04 | O sistema deve permitir o cadastro de eventos escolares |
| RF05 | O sistema deve permitir que os alunos consultem provas, trabalhos e atividades cadastradas |
| RF06 | O sistema deve organizar as atividades de acordo com suas respectivas datas |
| RF07 | O sistema deve permitir a atualização de informações cadastradas |
| RF08 | O sistema deve permitir a consulta dos eventos escolares cadastrados |

---

## 3. Requisitos Não Funcionais

| Código | Descrição |
|--------|-----------|
| RNF01 | O sistema deve possuir uma interface simples e fácil de utilizar |
| RNF02 | O sistema deve funcionar em computadores e dispositivos móveis |
| RNF03 | O sistema deve apresentar as informações de forma organizada |
| RNF04 | O sistema deve apresentar as informações de maneira rápida |
| RNF05 | O sistema deve garantir a segurança das informações cadastradas |

---

## 4. Regras de Negócio

- **RN01** - Toda atividade cadastrada deve possuir uma data
- **RN02** - Toda prova deve estar vinculada a uma disciplina e possuir uma data
- **RN03** - Todo trabalho deve possuir uma data de entrega
- **RN04** - Apenas usuários autorizados poderão cadastrar ou alterar informações
- **RN05** - As atividades devem ser organizadas de acordo com suas datas

---

## 5. Tecnologias Previstas

- **Front-end:** HTML, CSS e JavaScript
- **Back-end:** a definir durante o desenvolvimento
- **Banco de dados:** a definir durante o desenvolvimento
- **Versionamento:** Git e GitHub
