# 📚 Agenda CTBJ — Organização Digital da Rotina Escolar

## Projeto Integrador II

Sistema web desenvolvido para auxiliar os alunos do CTBJ na organização de sua rotina escolar, reunindo informações sobre provas, trabalhos, atividades e eventos em uma única agenda digital.

---

## 📌 1. Descrição do Projeto

O **Agenda CTBJ** é uma aplicação web desenvolvida como parte do **Projeto Integrador II**.

A proposta do sistema é facilitar o acompanhamento das principais atividades escolares, permitindo que informações importantes sejam cadastradas, consultadas, organizadas e atualizadas em um único lugar.

---

## ❗ 2. Problema

Os alunos precisam acompanhar diversas atividades, provas, trabalhos e eventos durante o período letivo.

A quantidade de informações pode dificultar a organização da rotina escolar e aumentar a possibilidade de esquecer datas importantes.

O Agenda CTBJ foi desenvolvido para centralizar essas informações em uma agenda digital de fácil consulta.

---

## 💡 3. Solução

A solução consiste em uma aplicação web que permite cadastrar e consultar informações escolares, organizando os itens de acordo com suas datas.

O sistema trabalha com quatro categorias principais:

- 📘 Atividades
- 📝 Provas
- 📑 Trabalhos
- 📅 Eventos

Também é possível:

- editar informações cadastradas;
- excluir informações;
- filtrar os itens por categoria;
- consultar os itens organizados por data.

---

## 🎯 4. Objetivo

Facilitar a organização da rotina escolar dos alunos do CTBJ, reunindo provas, trabalhos, atividades e eventos em uma única aplicação.

---

## 👥 5. Público-alvo

- Alunos do CTBJ;
- Professores do CTBJ.

---

## ⚙️ 6. Funcionalidades

O Agenda CTBJ possui as seguintes funcionalidades:

| Código | Funcionalidade |
|---|---|
| F01 | Cadastro de atividades |
| F02 | Cadastro de provas |
| F03 | Cadastro de trabalhos |
| F04 | Cadastro de eventos |
| F05 | Consulta dos itens cadastrados |
| F06 | Organização dos itens por data |
| F07 | Atualização de informações |
| F08 | Exclusão de informações |
| F09 | Filtro por categoria |
| F10 | Armazenamento dos dados no navegador |

### Categorias disponíveis

- **Atividade**
- **Prova**
- **Trabalho**
- **Evento**

Para provas e trabalhos, o sistema permite informar a disciplina.
