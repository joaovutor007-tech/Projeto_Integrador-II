# Relatório de Validação e Testes — Agenda CTBJ

## 1. Objetivo

Este documento registra os testes realizados no sistema Agenda CTBJ durante a etapa de execução, validação e entrega final do Projeto Integrador II.

Os testes tiveram como objetivo verificar o funcionamento das principais funcionalidades do sistema, a organização das informações e o acesso ao produto em diferentes dispositivos.

---

## 2. Ambiente de Testes

Os testes foram realizados utilizando:

- Navegador web em computador;
- Navegador web em celular;
- Versão publicada do sistema por meio do GitHub Pages.
